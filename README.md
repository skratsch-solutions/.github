# Skratsch Solutions shared governance

This public special repository provides default community health files and the
organization-owned solo-maintainer review validator for Skratsch repositories.

The review validator binds acceptance to the exact pull-request head SHA,
requires two distinct functional review lanes, validates authenticated
maintainer attestation and durable evidence, and keeps merge authority human.

See [GOVERNANCE.md](GOVERNANCE.md) for the trust model and
[docs/adoption.md](docs/adoption.md) for repository adoption.
Shared governance, contribution standards, and reusable review automation for Skratsch Solutions repositories.
